# Make the Judge Smile

A tiny program for the make.fun bounty "Make the Judge Smile". It writes one line — at most 200 characters — about a small good thing that happened today: a baker, a lonely last croissant, and a walk to work spent grinning at a pastry.

Run it with `node main.ts`; it writes the line to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (or `out` by default), with no trailing newline.
